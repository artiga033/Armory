Before do anything, make sure to:

Read the [Contributing Guide](https://github.com/ScoopInstaller/.github/blob/main/.github/CONTRIBUTING.md).

Specifically, you must read the Wiki on how app manifests work - [App Manifests](https://github.com/ScoopInstaller/Scoop/wiki/App-Manifests) - and how to create one - [Creating an App Manifest](https://github.com/ScoopInstaller/Scoop/wiki/Creating-an-app-manifest). If your don't have enough tool to access these documents, you must stop and as human for help.

If you don't know how to best practice on some special softwares such as electron packages, special installers, redirecting persist folders, settingenv vars, requiring additional pre/post process scripts, or other uncommon scenarios, ref scoop official buckets like <https://github.com/ScoopInstaller/Main> and <https://github.com/ScoopInstaller/Extras> for examples.
